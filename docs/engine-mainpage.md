# Welcome to the Unravel Engine C++ API

This is the C++ reference for the engine runtime library and the editor. Use
**Namespaces** and **Classes** for types and members, and **Files** to browse
the sources.

## Where the code lives

| Path            | Contents                                                                                     |
|-----------------|----------------------------------------------------------------------------------------------|
| `engine/core`   | Foundation: math, memory, filesystem, serialization, reflection, concurrency, graphics utils. |
| `engine/engine` | Runtime: ECS, rendering, assets, animation, physics, audio, input, UI, C# scripting host.    |
| `editor`        | Editor executable and ImGui hub. Not required at game runtime.                               |
