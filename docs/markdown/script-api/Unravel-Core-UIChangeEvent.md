# UIChangeEvent

> **Extends:** [`Unravel.Core.UIEventBase`](Unravel-Core-UIEventBase.md#uieventbase)

Represents a UI change event for handling string value changes. This is for text inputs, dropdowns, and other elements that provide string values.
