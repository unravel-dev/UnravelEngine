# UpdateInfo

Per-frame timing values pushed from native into managed code.

## Public Attributes

| Return | Name | Description |
|--------|------|-------------|
| `float` | [`time`](#time-3)  | Elapsed time in seconds since play began. |
| `float` | [`deltaTime`](#deltatime-2)  | Seconds since the previous update frame. |
| `float` | [`timeScale`](#timescale-1)  | Current time scale multiplier. |
| `long` | [`frameCount`](#framecount-1)  | Number of update frames since play began. |
